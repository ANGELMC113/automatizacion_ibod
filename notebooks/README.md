# Notebooks

Estos Notebooks contienen el análisis de datos, que sirve para luego crear los assets en Dagster.

Se organizan en carpetas por áreas de trabajo, subcarpetas por fuente y archivos por datasets fuente.

- Se separan las diferentes áreas debido a que suelen estar aisladas

- Se separan las diferentes fuentes debido a que cada una suele tener su propia forma de operar

- Se separan los diferentes datasets fuente cuando escala mal juntar demasiadas transformaciones en el mismo Notebook

(En la primera versión, solamente está DxVxM, pero se organiza así des del inicio para poder separar las diferentes áreas de trabajo en un futuro).
