# Notebooks

Estos Notebooks contienen el análisis de datos, que sirve para luego crear los assets en Dagster.

Se organizan en carpetas por áreas de trabajo y en archivos por datasets fuente.

(En la primera versión, solamente está DxVxM, pero se organiza así des del inicio para poder separar las diferentes áreas de trabajo en un futuro).
